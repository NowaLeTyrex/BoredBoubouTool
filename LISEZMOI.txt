BORED BOUBOU TOOL — v2.4.2
==========================

Fichiers à mettre à la RACINE du dépôt (pas dans un sous-dossier) :
  index.html, sw.js, boubou.webmanifest,
  boubou-192.png, boubou-512.png, boubou-maskable-512.png
Ce fichier LISEZMOI.txt est facultatif.

Mise à jour depuis une version précédente
  Supprime du dépôt les anciens fichiers, qui ne servent plus :
    manifest.json, icon-192.png, icon-512.png, icon-maskable-512.png

Mise en ligne (GitHub Pages)
  1. github.com → « + » → New repository → PUBLIC → Create.
  2. « Add file » → « Upload files » → glisse les 6 fichiers → Commit changes.
  3. Settings → Pages → « Deploy from a branch » → main, / (root) → Save.
  4. Adresse de l'app : https://TON-PSEUDO.github.io/NOM-DU-DEPOT/
     (et non github.com/..., qui n'affiche que les fichiers)

Installation sur Android (Firefox)
  5. Ouvre l'adresse dans Firefox, menu ⋮ → « Installer »
     (ou « Ajouter à l'écran d'accueil »).

Mettre à jour plus tard
  Remplace les fichiers sur GitHub et change le numéro dans sw.js
  (ligne CACHE = "boubou-v2.4.2"). GitHub Pages met jusqu'à 10 minutes
  à servir la nouvelle version.

Sauvegarde
  Les données restent uniquement dans le navigateur du téléphone.
  Réglages → « Exporter un fichier » de temps en temps.
