BORED BOUBOU TOOL — v2.4.1
=========================

Fichiers à mettre à la RACINE du dépôt (pas dans un sous-dossier) :
  index.html, manifest.json, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png
Ce fichier LISEZMOI.txt est facultatif.

Mise en ligne (GitHub Pages)
  1. github.com → « + » → New repository → nom « que-faire » → PUBLIC → Create.
     (GitHub Pages gratuit = dépôt public uniquement.)
  2. « Add file » → « Upload files » → glisse les 6 fichiers → Commit changes.
  3. Settings → Pages → Source : « Deploy from a branch » → Branch : main, dossier / (root) → Save.
  4. Attends 1 à 2 minutes. Adresse de l'app :
       https://TON-PSEUDO.github.io/que-faire/
     (et non github.com/TON-PSEUDO/que-faire, qui n'affiche que les fichiers)

Installation sur Android (Firefox)
  5. Ouvre https://TON-PSEUDO.github.io/que-faire/ dans Firefox.
  6. Menu ⋮ → « Installer » (ou « Ajouter à l'écran d'accueil »).

Mettre à jour plus tard
  Remplace les fichiers sur GitHub. Si tu modifies index.html, change aussi le
  numéro dans sw.js (ligne CACHE = "boubou-v2.4.1") pour que le téléphone
  récupère la nouvelle version.

Sauvegarde
  Les données restent uniquement dans le navigateur du téléphone.
  Réglages → « Exporter un fichier » ou « Partager la sauvegarde » de temps en temps.

Changement de nom (depuis « Que faire ? »)
  Tes activités sont conservées : elles sont liées à l'adresse github.io, pas au nom.
  L'icône et le nom sur l'écran d'accueil ne se mettent pas forcément à jour :
  supprime le raccourci, puis réinstalle depuis Firefox (menu ⋮ → Installer).
